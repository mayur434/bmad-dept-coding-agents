**Action vocabulary:**

- `scan` — a source agent (audit / sonar-scan / test-coverage /
  impact-analysis / code-review) produced a findings cache.
- `map` — Compliance mapped findings against a framework.
- `decide` — a `.bmad/decisions.yaml` entry was created/updated
  (`accepted` / `deferred` / `wontfix` / `fixed`).
- `remediate` — a finding's status advanced to `remediated` on a
  subsequent Compliance run (control-mapping row that was `gap`
  is now `covered` for the same control ID).
- `attest` — an `ATTESTATION.md` was authored with a named signer.

**Outcome vocabulary:** `findings-produced (N)`, `controls-mapped (N
covered / N gap)`, `risk-accepted`, `deferred (next-review: <date>)`,
`not-applicable`, `closed`, `signed-off`.
