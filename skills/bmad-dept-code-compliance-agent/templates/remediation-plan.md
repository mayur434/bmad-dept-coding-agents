## Owner assignment note

Every `Owner` field above is intentionally blank at authoring time.
The Compliance agent identifies WHAT needs remediation and BY WHEN
(via SLA); it does not assign engineers. Assign owners during the next
team planning session, then re-run compliance with the same framework
set to confirm the plan reflects current ownership — or track
assignment directly in your ticketing system via the `Tracking ticket`
placeholder.
