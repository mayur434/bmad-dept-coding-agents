## How to read this file

One entry per breaking change detected in the diff. **MUST-COMMUNICATE**
changes will break at least one known consumer and require a changelog
entry + migration note before merge. **SHOULD-FLAG** changes are
technically breaking (a public signature changed) but the blast radius
is unclear or likely low — flag for reviewer judgment rather than block.
