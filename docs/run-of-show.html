Field notes — if it goes sideways

The docs site is slow or unreachable on the day
Fall back to the local Markdown source under website/docs/ in an editor split pane — same content, same click order, just not rendered.
The install prompt is slow or awkward on camera
You pre-warmed deps in the prep checklist for both audit and generation — this shouldn't happen. If it does anyway, use --yes-install and narrate over it instead of waiting in silence.
The AEMaaCS audit comes back with zero findings
Say it straight: "A clean report is still a report — this is exactly what a CI gate checks for on every merge." Don't scramble for a dirtier project mid-recording.
Generation picks a different artifact than the Plugin shown here (an Observer, a second Controller, etc.)
That's the demo working, not breaking — call it out: "See, it read the BRD differently than I guessed — that's interpretation, not a hardcoded flag." Walk whatever it actually produced.
Generation is taking too long live
Cut to a result generated minutes earlier: "I ran this moments ago — here's the output," then walk the generated files and report as planned.
No real Commerce/AEM project available on the day
Fallback: use the Generation agent to scaffold a minimal AEM component and a bare Commerce module first (as a 30-second bonus beat), then run both demos against those instead.
The chat prompt asks a clarifying question instead of running one-shot
Normal — one-shot resolution depends on the AI tool reading the agent's SKILL.md exactly. Answer the one question it asks (usually stack or diff scope) and it proceeds; or switch to Option B (CLI) for that beat without breaking stride.
